# v1.5.0

修复WebDAV/CGI真实目录隔离、404封禁计数与安装包校验问题，并整合管理接口、配置安全及运行性能改进。

- WebDAV与CGI按真实目录检查隔离，运行中替换目录会拒绝请求；Linux CGI工作目录绑定已打开的目录描述符。
- 404计数回收过期来源，正常请求不占用新槽位；保留限速及CC计数的定时清理，防护事件和日志改用有界环形缓冲，日志分页使用稳定游标。
- 配置目录拒绝符号链接、非属主可写等不安全状态，损坏加密信封拒绝覆盖；首次密码保存在0600文件中，服务模式不把明文密码写入系统日志。
- 管理接口在读取期间会话失效时返回401；备份导入支持更大请求并报告重载告警；增加外部命令超时、通知限流退避、容量丢弃可见性及采样/证书缓存优化。
- `.run`校验覆盖整个安装载荷，拒绝链接、特殊文件和清单外文件，兼容BusyBox tar；支持`--check`与可选`--pubkey`。正式包沿用原Ed25519签名密钥，只提供五架构`.run`与`checksums.txt`。

在192.168.199.7清理旧插件后完成候选包全新安装；设备上四个Go包159项顶层测试通过，原账号、3个DDNS任务、2个站点、2条转发及1张证书恢复并验证。新装与恢复后分别通过21个HTTPS认证只读接口、71个嵌入资源校验；配置、密钥、证书及网络/防火墙保持原值。

本地Go全仓race/vet、前端79项测试及五架构构建通过。未做整机重启、其它架构硬件、公网DNS写入或实体手机验收。详见[修复记录](../security-fixes-2026-10-15.md)与[设备验证数据](../v1.5.0-device-validation.json)。
