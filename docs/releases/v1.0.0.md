# v1.0.0

网络服务控制台统一为暖灰背景、白色卡片与青蓝主色，独立导航图标、字段提示和窄屏长表单；设置、日志、通知、转发与隧道页面统一布局。

- DDNS 保留阿里云、Cloudflare、DNSPod；支持A/AAAA、静态CNAME/TXT、STUN/DNS与顺序回退来源、逐条启停及同步历史。
- Web 服务支持独立后端池、加权调度、并发预算和健康检查，CORS/响应头/路径改写，受控发现、WebDAV和CGI。
- 证书支持PEM导入、EAB、CA信任/传播参数与受控本机映射；概览支持资源图表及可选持久历史。
- 防护中心支持共享策略、安全组、请求侧WAF/CC，以及TCP诱捕、IP/CIDR豁免、自动到期和手动解封。管理入口独立。
- **安装文件仅提供 `.run`**：x86_64、arm64、armv7、mips、mipsle。`checksums.txt` 用于核对下载；手动更新验证内置Ed25519签名。
- 新增 `sh <安装文件>.run --check`：检查系统/CPU、MIPS大小端、必要工具、CA证书、可用空间与载荷摘要/版本。无需Go或Node.js；升级保留账号、配置、设备密钥与证书。隧道功能的cloudflared是可选独立依赖。

GeoIP、跨设备证书同步及其它未开发增强项不包含在此版本。实际验证记录见仓库docs；窄屏浏览器检查不等同于真实手机验收。

构建工具链固定为Go 1.27.2，HTTP/2依赖更新为golang.org/x/net v0.60.0；发布前重新执行完整并发测试与漏洞扫描。
