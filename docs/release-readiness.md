# 上线候选版本验收（2026-10-04）

本轮完成浅色蓝灰后台、菜单分组、LuCI 整理、cloudflared 官方下载和上线缺陷修复。候选版本为 `release-candidate`。**尚不能标记正式发布验收完成**：真实 Cloudflare 公网场景、正式签名安装包和 ARM 真机运行仍需验收。

此前 Tunnel 集成和六项审查修复的历史结果见 [集成验证](tunnel-validation.md)、[此前真机验证](tunnel-device-validation.md)。以下是本轮新增结果，覆盖 UI、下载和四项上线问题。

## 已完成功能

- 菜单保留原 URL，按概览、流量与接入、域名与证书、系统与运维分组。白色表面、浅灰背景、蓝色主操作；统一状态文字、按钮层级、间距、圆角和表格。
- Dashboard 聚焦健康、流量和异常；主程序升级、备份移到设置页。隧道列表主要提供启停和详情，其他操作放入“更多”；详情包含配置、路由和日志，区分草稿、发布、进程和就绪状态。
- Linux x86_64、ARM64、ARMv7 自动匹配官方 cloudflared 资源，查询稳定版本并缓存一小时，用户点击安装或更新。MIPS/MIPSLE 不提供自动下载，主项目仍保留构建。
- 流式下载、80 MiB 上限、磁盘预检、官方 HTTPS 来源及重定向限制、官方 SHA-256、ELF 架构和版本校验。下载完成前保留旧程序；受管理版本位于配置目录 `runtime/cloudflared`，系统安装保留。
- 安装使用持久化后台任务，展示阶段、字节进度、错误。更新列出启用实例，要求管理密码和重启确认；列表变动后拒绝旧确认。失败恢复旧程序及原启用状态；服务启动恢复切换日志、清理中断下载并标记中断任务。
- LuCI 使用系统原有表单、状态标签与主题，整理运行状态、后台入口及登录说明；明确后台账号独立于路由器 root 账号。

## 缺陷修复及证据

| 缺陷 | 修复 | 验证 |
| --- | --- | --- |
| 并发登录绕过新启用 TOTP / 改密或恢复后签发新会话 | 认证代际、凭据快照校验；变更、撤销、挑战及会话签发使用统一锁 | 暂停密码检查期间并发改密、启用 TOTP、备份恢复；旧挑战、旧会话及慢请求体失效 |
| Linux 升级失败回滚定位错误 | 替换前固定正式可执行文件路径，安装与恢复使用同一路径；报告回滚错误 | Linux 独立测试进程实际重命名自身程序，注入保存失败、重启失败，校验原路径文件恢复 |
| 保存 Tunnel 草稿中断旧发布路由 | 保留期望、已发布、待提交及待清理入口；只识别本机确定的 Socket 路径 | 改名、删除、站点切换、直连切换及同步失败保留旧域名、Socket 和站点删除保护；确认移除后撤销 |
| 站点停用后 SSE 长响应继续转发 | 五秒 Shutdown 超时后强制 Close，关闭已跟踪 WebSocket | SSE 后续字节拒绝转发且后端请求取消，普通与专用入口连接分别验证 |
| 隧道入口撤销后已升级连接继续存活 | 专用入口跟踪全部连接，撤销时关闭普通和劫持连接 | 撤销 UDS WebSocket 的同时保留普通 TCP WebSocket |
| 安装/任务启动与服务关闭并发可能错误使用 WaitGroup | 启动注册与关闭使用生命周期锁 | 完整竞态测试、取消与重启恢复测试 |
| 程序在下载阶段退出遗留部分文件 | 启动时即清理安全目录中的部分下载与临时日志，无需先存在切换日志 | 下载前切换中断恢复回归、实际 Linux 运行 |
| 旧卸载脚本未删除带后缀的 LuCI 缓存 | 安装、卸载脚本清理实际缓存文件；同步删除卸载程序，避免延迟删除影响重装 | 真机确认旧卸载残留 `.json` 缓存，修复后卸载清理及立即重装通过 |
| 新增分页、描述和进度控件缺少样式 | 补齐现有 Element Plus 样式导入 | 浏览器复查设置分页、详情及真机 100% 安装进度 |
| 前端构建依赖存在高危告警 | 去掉旧 i18n 插件，复用已存在的编译工具编译四个固定语言文件；更新 brace-expansion | 国际化回归、30 项前端测试、生产构建，npm audit 为 0 |
