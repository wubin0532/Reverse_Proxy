# v1.5.1 安全、性能与 UI 修复及设备验证

本次修复对应 [2026-10-15 再审查的七项问题](review-security-performance-ui-2026-10-15.md)。基线为 v1.5.0 / `5694aa27c63bb3a5df5a5f2ab37f75b78629cebc`，版本统一更新为 v1.5.1。

## 修复范围

| 问题 | 修复 |
|---|---|
| 空站点白屏 | API 保持空规则为数组；UI 同时兼容旧响应的 `rules:null`，可正常添加首条子规则 |
| 撤销会话后日志继续推送 | 会话撤销、淘汰会通知已有订阅；日志流每次写入复核会话，注销和全局撤销立即关闭。写入期间使用 5 秒期限，成功刷新后清除期限，兼容 HTTP/2 空闲日志流 |
| 只读角色可读初始密码 | 初始密码读取移入 LuCI 写角色；只读界面显示权限说明，rpcd 独立强制执行权限 |
| 恢复告警被吞掉 | 部分恢复失败显示常驻告警；跳转登录、重新登录和刷新后仍保留，直到明确确认。恢复期间的后台轮询 401 不会抢先卸载结果页面 |
| 慢上传超时 | 大上传读取预算 10 分钟、最终响应预算 12 分钟、页面等待 13 分钟；展示上传进度。备份恢复也使用相同页面等待预算 |
| 静态资源未压缩 | 构建阶段生成 gzip/Brotli；按 Accept-Encoding 协商，设置 Vary 和各表示独立 ETag；支持 HEAD、条件请求和字节范围。设备不执行在线压缩 |
| 移动端点击区域偏窄 | 顶部导航、刷新和语言区域至少 44×44px，账号区域实测 68×44px |

## 保护与验收边界

- 安装前备份原程序、旧回滚程序、加密配置、设备密钥、证书、UCI、网络、防火墙及 rpcd 配置，并在本机逐文件核对关键文件摘要。
- 正式应用的独立管理员账号保持原值。本轮提供的设备管理凭据没有通过正式应用登录；认证业务流程在设备独立实例验证，不能将其写成原业务账号登录成功。
- 不进行真实 DNS/Cloudflare 写入、整机重启、其它架构硬件验收或实体手机验收。
- 候选测试凭据、Cookie、备份口令和设备备份未写入仓库。证据仅保留经过筛选的测试输出与截图。
