另使用隔离配置与正式二进制，通过实际 HTTPS 管理接口和官方 cloudflared 验证：

- 未登录返回 401；首次登录要求改密；受限接口返回 403；修改临时配置密码后撤销旧会话。
- 安装前报告 cloudflared 缺失；安装后识别 2026.9.3、路径和兼容性。
- 无效 Token、Tunnel ID 不匹配被拒绝；Token 单独接入提取 ID；空白更新保留密钥；接口及日志不包含测试 Token。
- 无 API 凭据时云端视图只读；同步后台任务返回“账户凭据不存在”，未创建远端资源。
- 直连目标拒绝内嵌凭据及本机管理端口；HTTPS 默认验证证书。
- 官方 cloudflared 接受当前参数并启动；Token 从文件传入，命令行没有密钥。实际文件 `0600`，目录 `0700`。
- 格式正确但无效的测试凭据保持连接未就绪；不会把进程存在显示为连接成功。
- 对实际 cloudflared 子进程发送 SIGKILL 后，管理器自动启动新进程；显式停止后不再启动，清理 Token 文件。
- 启用站点路由后创建专用 Socket，权限 `0600`，目录 `0700`；删除被引用站点返回 409。
- 加密备份恢复健康检查间隔及其他参数，保留 Token，所有隧道默认停用；进程重启后保持恢复结果。
- 原 0.3.5 加密配置和密钥的隔离副本可由新程序启动。
- 正式 procd 服务启用且运行，服务重启保留配置、密钥及初始密码文件；LuCI 菜单、ACL 和页面文件存在。
- 直接通过设备 HTTPS 地址取得 56 个前端文件，逐文件 SHA-256 与当前构建一致，共 1,300,619 字节。
