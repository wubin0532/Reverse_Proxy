# Lucky 五模块第二轮审查与修正

> 后续已完成 PVE 路由器实测并修复背景、图表裁切和窄屏容器问题，当前部署状态见[PVE 实测记录](pve-router-acceptance-2026-10-13.md)。

日期：2026-10-13。基线：`180f365bd5031492a781c77bb141963aa20d9b05`。本轮代码在 `codex/lucky-workspaces` 本地工作区，尚未提交、推送或部署。

前一轮“完成 A+B”的结论过宽：虽然主要接口与服务已接入，但再次审查发现 DDNS 请求合同、并发更新和视觉排版仍有缺陷。本报告记录修正后的状态。它不意味着 Lucky 的全部功能已复刻，也不意味着路由器现网已验收。

## 证据与实现边界

参考依据包括已登录 Lucky 的实际页面、发布前端与上一轮 REA 记录。页面层可以确认字段、交互、布局和调用行为；未取得 Lucky 后端源码，其调度、缓存和底层算法属于推断。本项目实现依据自己的 Go/Vue 架构，不把推断写成 Lucky 后端事实。

检查范围为动态域名、Web 服务、证书、防护中心、总览。保留用户确定的三家 DDNS 服务商：阿里云、Cloudflare、DNSPod。

## 功能问题与修正

| 发现的问题 | 本轮修正 | 验证 |
|---|---|---|
| DDNS 新建表单传入后端不接受的 revision，保存返回 400 | 新建省略 revision，编辑携带当前版本 | 真实本地浏览器新建并保存停用任务，列表出现新任务；HTTP 路由回归 |
| 任务启停、删除可以接受陈旧版本 | 新记录模型要求当前 revision，旧单记录调用保留兼容 | 当前版本成功、陈旧/缺失版本拒绝测试 |
| records=[] 可以把新任务降回旧结构，绕过记录版本检查 | 禁止此类无版本降级 | 回归测试 |
| 删除记录后仍保留地址缓存 | 按有效任务及记录清理缓存、状态和历史 | 缓存清理测试 |
| 409 后表单无法恢复到最新版本 | 保留草稿、阻止反复提交，提供明确放弃草稿并重新载入操作 | DDNS 组件回归 |
| 新增任务不能在表单里选择先停用 | 添加任务启用开关 | 实际浏览器关闭开关后成功新建；未执行外部 DNS 写入 |
| 同规则重新打开时旧健康响应可能覆盖新草稿 | 编辑代次和请求编号隔离，失败禁止保存并可重试 | 异步旧响应/失败重试回归 |
| Web 防护数把普通头部误计为策略，遗漏全局策略或临时封禁 | 根据真实站点、规则、全局策略和临时封禁计算；失败状态显示未知 | Web/Protection 组件回归 |
| 证书文件异步读取可能落入重新打开的表单 | 文件读取与当前编辑代次绑定 | 延迟读取回归；真实菜单与替换表单打开检查 |
| 证书服务商、站点证书引用仅在提交前验证 | 配置提交锁内再次检查引用，保留保存错误的正确状态码 | 提交引用校验回归；未模拟完整 HTTP 竞争时序 |
| ACME 更新状态清理可能碰到并发导入后的对象 | 清理前重新检查当前来源、域名、算法 | 全量竞争检测通过；实际公网 CA 未验收 |
| 资源图跨睡眠/缺采样连线、网络历史不足、图轴不易读 | 显式 null 断点；5 秒/分钟历史带网卡速率；24 小时时钟和 B/s、KB/s、MB/s 刻度 | 历史与格式回归；真实浏览器检查 |
| 不支持的网卡累计显示为 0 | 根据指标支持状态显示不可用／待采样 | 当前 macOS 本地预览可见 |

## 布局、字体与美术

Lucky 实页可见的设计特征是约 196px 侧栏、20px 主标题、14px 正文、13px 列表文字、12px 辅助文字，以及浅蓝层次、12px 圆角、轻阴影。此前项目主要沿用大标题、白色 Element Plus 卡片和展开式表格，与参考页面的信息密度差异明显。

本轮统一了侧栏和页头、浅蓝背景与表面、主蓝色、字体层级、圆角、阴影、状态筛选和主要操作位置。没有引入图像装饰或未经打包的外部字体。保留项目品牌和现有能力边界。

| 模块 | 结构调整 |
|---|---|
| 总览 | 资源卡片与资源/网络趋势前置，服务状态下移；支持暂停刷新；错误和系统运维信息保留在下方 |
| 动态域名 | 任务标题、摘要、启停与更多菜单；任务展开后展示记录；桌面手机共用结构；取消重复的大统计区 |
| Web 服务 | 站点标签、紧凑摘要、分组筛选、按顺序的子规则列表；流量趋势默认收起；编辑器按基础/访问控制/高级/健康分区，后两项随规则类型出现 |
| 证书 | 名称/域名、到期、来源算法、状态绑定、操作形成紧凑行；主要操作和更多菜单分开，手机改为卡片 |
| 防护中心 | 策略/封禁/事件分页；紧凑计数；展示真实绑定对象及全局状态，手机改为卡片 |

真实浏览器测量：五模块桌面 1440px、手机视口 390px 均满足 `scrollWidth == viewport`。主标题均为 20px/650，正文 14px；主标题行高 26px（DDNS、防护为 28px）。手机输入为 16px，主要操作目标 44px。这是响应式浏览器检查，未代替真实手机验收。视觉结果为借用参考布局后的项目版本，未宣称逐像素复刻。

## 尚未完成与下一阶段

- 尚未部署到 OpenWrt/LibWrt，未验证真实 Linux /proc 指标曲线、路由器性能、真实手机、公网 DNS/CA、现网 Tunnel 或防火墙。
- 尚未开发：STUN/DNS 来源回退、更多记录类型、EAB/传播参数/文件映射、独立后端池、持久指标历史、身份安全组、GeoIP、WAF/CC、诱捕、服务发现、WebDAV/CGI、远程证书同步。扩大 DDNS 服务商不在需求中，仍保持三家。
- 指标历史、防护事件与临时封禁是有界进程内存，重启清空；默认网卡速率当前依赖 IPv4 默认路由。业务字节统计仍沿用现有口径，未覆盖完整未知长度上传和 SSE/WebSocket 实时字节统计。临时封禁不会主动断开已有 TCP/WebSocket。
- 配置导出不包含 certs/ 的证书私钥材料，文件级迁移须同时保存配置目录、其同级 `.key` 加密密钥与证书材料。这里记录实际能力，不把配置导出当作完整证书迁移。
