## 实施顺序与验收

1. DDNS：STUN 与 DNS 来源、顺序回退、源预览、CNAME/TXT 静态值；三家模拟 API 实测，UDP STUN/DNS 真正收发，错误/取消/超时回退。
2. 证书：EAB、传播与递归 DNS 参数、受控证书映射；凭据读取脱敏、未提供新密钥保留、变更后取消旧申请；映射失败可见与证书替换一致性。
3. Web：独立加权后端池及健康、错误响应/CORS/响应头/路径改写；业务上传不重放。随后受控服务发现、WebDAV、CGI。
4. 总览：容量受控持久历史，重启恢复；采样不重复，损坏/未来格式不阻断启动，写盘频率受限。
5. 防护：身份组/用户/作用域会话与撤销；GeoIP 本地库、WAF/CC、诱捕。每项独立开关，管理入口独立，所有状态和资源有容量上限。
6. 跨设备证书同步：明确目标、TLS 校验和单独权限、受控替换及重试；不在控制台返回私钥。
7. 回归、生产构建、PVE 隔离验收，再升级系统服务；保留原配置、密钥、证书和管理员口令。
