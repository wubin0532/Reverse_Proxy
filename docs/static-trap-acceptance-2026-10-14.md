# 静态 DNS 记录与 TCP 诱捕验收

2026-10-14 用户收窄范围：只开发三家服务商的静态 CNAME/TXT，以及 TCP 端口诱捕、自动封禁与解封。GeoIP、跨设备证书同步及其它未开发增强项退出本轮待办。既有已实现功能保留。

## 已实现

- DDNS 保留阿里云、Cloudflare、DNSPod。在现有任务/逐条记录编辑器中增加 CNAME/TXT 与固定记录值；不查询本机 IP，记录值或 TTL 变更会核查远端，强制核查修复漂移；沿用 revision 冲突保护和100条运行历史。
- CNAME 目标归一化并拒绝 IP、URL、自身域名及非法标签；TXT 原文保存，不改变大小写、空格和引号，限定2048字节，拒绝换行/NUL。
- 同名同类型多条远程 CNAME/TXT 拒绝修改；查询满100条时拒绝不完整核查。Cloudflare 用 PATCH 保留其它字段并保留 CNAME 代理状态；DNSPod 保留线路，Record.List 空结果代码10允许创建。
- 停用/删除记录只停止本任务管理，不删除云端记录；同一任务目前只管理每个域名/类型的一条记录。多条 TXT 应先在服务商控制台整理，避免误覆盖其它业务记录。
- 防护中心新增 TCP 诱捕页，支持独立启停、IPv4/IPv6监听地址、最多20个端口、IP/CIDR豁免、1秒至30天封禁时长、运行状态/错误/计数，难理解开关旁提供问号提示。
- TCP 握手完成即捕获来源并关闭连接；不读取负载，不为每个连接创建协程。本机回环和匹配豁免名单的来源不捕获。复用最多2048条封禁与512条事件的容量上限。
- 封禁对本插件 Web 与 TCP/UDP 转发生效，管理后台独立；支持自动到期、现有临时封禁页手动解封。此功能不修改系统防火墙或封禁其它程序；WAN诱捕端口需要用户自行放行。
- 监听新端口先全部预绑定，端口冲突或写盘失败保留旧配置和旧监听；禁用关闭监听，导入/启动失败明确显示停止与错误。配置随加密备份保存，进程启动恢复监听。临时封禁/计数/事件重启清空。
